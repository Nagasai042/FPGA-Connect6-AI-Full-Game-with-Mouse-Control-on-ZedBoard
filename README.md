# FPGA-Connect6-AI-Full-Game-with-Mouse-Control-on-ZedBoard
A real-time Connect6 board game on Xilinx Zynq-7000 FPGA. Human vs FPGA AI over UART, with 1920×1080 VDMA video output and mouse-based input via ZyMouse IP. Features color selection, live move counters, turn indicators, win detection in all directions, and winning stone highlights.
